# Formal Verification (`TLA+` & `Lean 4`)

This directory contains machine-checked formal specifications, runtime trace conformance, and unbounded Lean 4 proofs for the concurrency protocols, mathematical TTL policies, payload/numeric bounds, and HTTP cacheability invariants of `@0xdoublesharp/adaptive-cache`.

## Overview

| Layer                                        | Tool           | Artifacts                                                                                                                                              | Properties Verified                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Coalesced loading & lock leases              | **TLA+ (TLC)** | [`tla/CacheLoaderCoordination.tla`](tla/CacheLoaderCoordination.tla)                                                                                   | **Safety:** mutual live lock ownership; atomic compare-and-delete lock release preserving successor leases (Redis & clustered-LRU primary); expired-lease write rejection (atomic Redis Lua path); caller deadline/abort isolation; negative entries having no stale window; no background SWR fallback leaking to foreground callers; bounded `close()` rejection. **Liveness (WF):** every waiting/retrying caller eventually resolves; closing instances eventually drain; every lock is eventually released or expires. |
| Fastify coalesced loader publication         | **TLA+ (TLC)** | [`tla/FastifyCoalescedPublication.tla`](tla/FastifyCoalescedPublication.tla)                                                                           | **Safety:** uncacheable/rejected leader responses (e.g. `Cache-Control: private`, `Set-Cookie`, `Vary: *`) are never published to waiters or stored in cache; waiters receive published responses only after `onSend` approval; `private` responses never leak across coalesced requests. **Liveness (WF):** every waiter eventually resolves (either via leader publication or private fallback).                                                                                                                          |

## Running Locally

```bash
# Run all four TLA+ specs with TLC (requires OpenJDK 21+ and tla2tools.jar)
pnpm run verify:tla

# Run runtime trace conformance against real Redis + TLC (requires Docker, Java, tla2tools.jar)
pnpm run verify:trace

# Compile and verify all Lean 4 proofs (requires elan / Lean 4.35.0)
pnpm run verify:lean

# Run both TLA+ specs and Lean 4 proofs
pnpm run verify:formal
```

Set `TLA2TOOLS_JAR=/path/to/tla2tools.jar` if `tla2tools.jar` is not in a standard location.
All Lean 4 proofs compile with zero external dependencies and zero `sorry`.
